# Щоденник витрат

Навчальний вебзастосунок на HTML, CSS і JavaScript. Сервер, база даних і React не використовуються. Витрати зберігаються в `localStorage` браузера. Паролі з форми реєстрації не зберігаються.

## Як відкрити

Відкрийте `index.html` у браузері. Окремий сервер не потрібен.

- [index.html](index.html) — трекер витрат і статистика.
- [register.html](register.html) — форма реєстрації.

## Завдання 1. Трекер витрат

- Форма з назвою, сумою та категорією: Їжа, Транспорт, Покупки, Інше.
- Кнопка «Додати витрату».
- Список витрат картками.
- Видалення окремої витрати.
- Автоматичний підрахунок загальної суми.
- Перевірка: порожня назва і сума, яка не більша за нуль, не зберігаються. Помилка з’являється під полем.
- Записи лишаються після перезавантаження через `localStorage`.

## Завдання 2. Реєстрація

Перевірка виконується в JavaScript без перезавантаження сторінки.

- Ім’я — щонайменше 3 символи.
- Email у форматі `ім’я@домен.зона`.
- Пароль — щонайменше 8 символів.
- Підтвердження пароля має збігатися з паролем.
- Без позначки «Погоджуюсь з умовами» форму надіслати не можна.
- Помилки показано під відповідними полями.
- Якщо все правильно, з’являється повідомлення «Реєстрація успішна!».
- Це навчальна форма: обліковий запис не створюється, пароль ніде не записується.

## Завдання 3. Статистика

- Фільтр списку за категоріями.
- Пошук за назвою під час введення.
- Окрема сума для кожної категорії.
- Кнопка «Очистити всі витрати» спочатку просить підтвердження.
- Після додавання, видалення й очищення сторінка та `localStorage` оновлюються разом.
